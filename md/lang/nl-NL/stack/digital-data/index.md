# 5.1 The Stack :: Digital Data

## Uitgebreide bespreking

### Actieve computerleesbare informatie

**Digital Data** is Layer 7 van de Stack. Deze laag vertegenwoordigt informatie nadat zij de actieve interfaceflow is binnengekomen in een vorm die de computer kan lezen, maar voordat het Model haar heeft geïnterpreteerd, georganiseerd of gepresenteerd. Digital Data kan een bestand, document, stream, buffer, web response, database result, message of andere computerleesbare representatie zijn.

Digital Data is niet hetzelfde als betekenis. Zij kan betekenis bevatten, maar die betekenis is nog niet door het Model uitgelegd. Een tekstbestand kan zinnen bevatten, een afbeelding kan pixels bevatten en een audiobestand kan geluid beschrijven, maar zolang de interface alleen met de actieve digitale representatie werkt, is de data nog niet omgezet naar structurele, semantische of zintuiglijke vorm.

### Van opslag naar actieve flow

Digital Data is het punt waarop informatie vanuit Data Storage de expliciete Stack binnengaat. Een bestand dat op schijf staat, is opslag. Wanneer het wordt gelezen en de bytes in de actieve flow worden gebracht, hebben we Digital Data. Een database kan de bron zijn, maar het queryresultaat waarmee de interface werkt is Digital Data. Een server kan een response sturen, en die response wordt Digital Data zodra de interface hem behandelt.

Dit onderscheid is belangrijk omdat de Stack de beweging van actieve informatie beschrijft. De opslaglocatie kan verschillen, maar zodra de data actief wordt, kan het Model haar op dezelfde manier volgen.

### Nog geen domain-toewijzing

Digital Data is meestal nog niet aan een zintuiglijk domain toegewezen. Een tekstbestand is niet automatisch visual omdat het later op een scherm kan verschijnen, en niet automatisch auditory omdat het kan worden voorgelezen. Op Layer 7 is het simpelweg een digitale representatie. Latere lagen bepalen hoe die representatie wordt geïnterpreteerd, gebruikt, georganiseerd en uiteindelijk in een of meer domains wordt uitgedrukt.

Dit geeft Digital Data flexibiliteit. Dezelfde data kan naar verschillende ervaringen leiden. Een document kan visueel worden weergegeven, auditief worden voorgelezen, symbolisch worden geanalyseerd, of naar braille worden vertaald. Layer 7 bewaart de actieve digitale vorm voordat zulke beslissingen volledig zijn gemaakt.

### Relatie met Structure & Semantics

Digital Data moet door Structure & Semantics worden geïnterpreteerd voordat de rest van de interface haar betekenisvol kan gebruiken. De bytes van een bestand vertellen het systeem niet vanzelf welke delen headers zijn, welke delen waarden zijn, welke regels gelden of welke fouten mogelijk bestaan. De Data-connector brengt Digital Data naar Layer 6, waar de juiste semantics en structures kunnen worden toegepast.

Daarom is Layer 7 bewust eenvoudig. Het vertegenwoordigt wat er actief beschikbaar is, niet hoe alles moet worden begrepen. Die scheiding voorkomt dat elk bestandstype, protocol of datastructuur direct in Digital Data zelf wordt gepropt.

### Rol in de omgekeerde stroom

Wanneer een user interaction uiteindelijk blijvende informatie wijzigt, kan de stroom terugkeren naar Digital Data. Een bewerkt document, gewijzigde instelling of bijgewerkt record moet opnieuw in een computerleesbare vorm worden geproduceerd voordat het kan worden opgeslagen, verzonden of verder verwerkt. In die richting is Digital Data het punt waarop geïnterpreteerde en gewijzigde informatie weer actief digitaal materiaal wordt.

### Waarom de laag ertoe doet

Digital Data houdt de Stack eerlijk over het verschil tussen beschikbaarheid en begrip. Informatie kan beschikbaar zijn voor de computer zonder dat zij al betekenisvol is voor de interface of waarneembaar voor de gebruiker. Door Digital Data als eigen laag te benoemen, krijgt het Model een duidelijke plaats voor actieve, computerleesbare informatie vóór interpretatie.

Dit is het bovenste expliciete keerpunt van de Stack: opgeslagen inhoud kan hier de interface binnengaan, en gewijzigde inhoud kan hier terugkeren voordat zij opnieuw wordt bewaard.
