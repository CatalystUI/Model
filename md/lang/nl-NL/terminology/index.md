# 1. Terminology

## Fundamenten

Voordat we beginnen, is het belangrijk om algemene termen te verduidelijken die door de documentatie heen worden gebruikt, omdat lezers uit verschillende achtergronden kunnen komen. Hoewel deze termen bekend kunnen zijn voor mensen met ervaring in gebruikersinterface-ontwerp, zullen veel ervan afwijken van hun traditionele betekenis. Ze worden opnieuw geïntroduceerd om de gebruikte taal te verfijnen, te verduidelijken en te verenigen.

---

### Process

Een *process* is iets dat een *input* accepteert, een *transformation* uitvoert en een *output* produceert.

### System

Een *system* is een georganiseerde verzameling processen, gedefinieerd door hoe zij interageren en de volgorde waarin zij worden uitgevoerd.

### Interface

Een *interface* is een mechanisme waardoor twee verschillende systemen met elkaar kunnen interageren.

### Information System

Een *information system* is een gespecialiseerde vorm van system die werkt met “persistent data,” oftewel data die beschikbaar blijft buiten één enkel process, en die een gebruiker via een interface in de loop van de tijd kan maken, lezen, bijwerken of verwijderen.

### Computer

Een *computer* is een information system dat uitsluitend werkt met “digital data,” oftewel data die binair kan worden vertegenwoordigd en door een machine kan worden verwerkt.

### User

Een *user* is een persoon die met een information system kan interageren.

---

Daarnaast erkent de tekst dat men kan stellen dat de termen “data” en “information” verschillende definities hebben. Vanwege de manier waarop ze in het Model worden gebruikt, behandelen we de twee termen echter als uitwisselbaar.
