# 4.5 Domains :: Olfactory

## Uitgebreide bespreking

Na aanraking beschrijft het **olfactory** domain data die voor geur is gevormd. Olfactory data is informatie die bedoeld is om via reuk te worden waargenomen. Dit kan een geur zijn die een toestand, waarschuwing, omgeving, sfeer of andere betekenis communiceert. Waar visual data wordt gezien, auditory data wordt gehoord en tactile data wordt gevoeld, wordt olfactory data geroken.

Dit domain voelt in gewone software misschien ongebruikelijk, maar het is juist nuttig omdat het Model niet beperkt is tot traditionele scherminterfaces. Niet elke informatie-uitwisseling hoeft via pixels, tekst of geluid te verlopen. Een systeem kan geur gebruiken in training, simulatie, waarschuwing, omgevingsontwerp, onderzoek, toegankelijkheid of gespecialiseerde hardware. Zelfs als geur zelden wordt gebruikt, helpt het domain ons de mogelijkheid precies te beschrijven.

Een geurrecept, chemische beschrijving of opgeslagen opdracht om een geur te produceren is niet automatisch olfactory. Zolang die informatie alleen als data bestaat, is zij symbolic. Zij wordt olfactory wanneer het systeem haar omzet in een waarneembare geur die de gebruiker kan ruiken.

### Olfactory data begrijpen

Een nuttige manier om olfactory data te begrijpen is te kijken naar **identiteit**, **intensiteit** en **context**.

**Identiteit** beschrijft welke geur wordt gecommuniceerd. Een geur kan rook, voedsel, bloemen, schoonmaakmiddel, gevaar, comfort of een specifieke omgeving suggereren. De herkenbare aard van de geur helpt bepalen welke betekenis de gebruiker eruit haalt.

**Intensiteit** beschrijft hoe sterk de geur aanwezig is. Een zwakke geur kan sfeer toevoegen. Een sterke geur kan urgentie, nabijheid of waarschuwing communiceren. Intensiteit is belangrijk omdat geur niet alleen wordt herkend, maar ook lichamelijk wordt ervaren.

**Context** beschrijft waarom de geur wordt gebruikt. Dezelfde geur kan verschillende betekenissen hebben afhankelijk van de situatie. De geur van rook kan in een trainingssimulatie een gevaar aanduiden, in een kookervaring een normale gebeurtenis zijn, of in een entertainmentomgeving sfeer toevoegen. De geur draagt betekenis door haar relatie met de rest van de interactie.

### Olfactory betekenis

Olfactory output drukt betekenis uit via geur, maar de geur zelf is niet de volledige betekenis. Een rookgeur kan gevaar communiceren, maar is niet het gevaar. Een bloemengeur kan een omgeving of stemming suggereren, maar is niet de omgeving zelf. De betekenis komt uit hoe het systeem die geur gebruikt binnen de ervaring.

Geur is krachtig omdat zij snel associaties oproept. Zij kan herinnering, emotie, richting, waarschuwing of aanwezigheid ondersteunen. Tegelijk is geur minder precies dan tekst of beeld. Een geur kan duidelijk maken dat er iets aanwezig is, maar niet altijd exact uitleggen wat de gebruiker moet doen. Daarom werkt olfactory data vaak het best wanneer zij betekenis ondersteunt of versterkt die ook door andere domains wordt gedragen.

### Olfactory data en toegankelijkheid

Het olfactory domain kan in sommige situaties toegankelijkheid ondersteunen, maar het kan ook toegankelijkheidsproblemen veroorzaken. Geur kan nuttig zijn wanneer zicht of gehoor niet beschikbaar is, of wanneer omgevingsbewustzijn belangrijk is. Maar geur kan ook worden gemist door gebruikers met verminderd reukvermogen, kan ongemak veroorzaken, of kan medisch of omgevingsmatig ongeschikt zijn.

Domains helpen hier duidelijk maken waar betekenis wordt gedragen. Als een belangrijke waarschuwing alleen als geur bestaat, kan die waarschuwing voor sommige gebruikers onzichtbaar, onhoorbaar en onvoelbaar blijven. Door de betekenis ook symbolisch, visueel, auditief of tactiel beschikbaar te maken, kan het systeem dezelfde intentie beter bewaren.

### Olfactory data in bredere ervaringen

Olfactory data zal meestal deel zijn van een bredere multisensory ervaring. Een trainingssimulatie kan beeld, geluid, beweging en geur combineren. Een therapeutische of educatieve toepassing kan geur gebruiken om herinnering of herkenning te ondersteunen. Een gespecialiseerde waarschuwing kan geur combineren met licht of geluid om aandacht te trekken.

Kort gezegd beschrijft het olfactory domain informatie die is gevormd tot ruikbare output. Het helpt het Model compleet blijven, ook wanneer een interface buiten de traditionele computerervaring valt. Wanneer olfactory data goed wordt behandeld, kan geur betekenis ondersteunen, context versterken en de gebruiker op een extra zintuiglijk kanaal bereiken.
