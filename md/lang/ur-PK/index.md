# تعارف

CatalystUI Model (“the Model”) user-interface design کے بنیادی اصولوں کو پہچاننے اور سمجھنے کے لیے ایک عالمگیر زاویۂ نظر ہے۔ ایک ایسے زمانے میں جب بہت سے developers تنگ، مخصوص، اور الگ الگ مسائل حل کرنے کا انتخاب کرتے ہیں، CatalystUI Model ایک قدم پیچھے ہٹ کر user-interface design کو بطور تصور دیکھتا ہے۔ اس زاویے سے ہم مختلف حلوں میں مشترک patterns پہچان سکتے ہیں، ہر طریقۂ کار اور اس کی حدود کو سمجھ سکتے ہیں، اور جمع کی گئی معلومات کو استعمال کر کے ایک ایسا universal framework قائم کر سکتے ہیں جو end-user اور information system کے درمیان پورے interaction process کو بیان کر سکے۔

اس documentation کی ترتیب سمجھ کے تین درجوں میں رکھی گئی ہے—_beginner_، _intermediate_، اور _advanced_—جو تقریباً in-depth discussions، per-topic summaries، اور high-level overviews سے ملتے ہیں۔ اگرچہ ہم terminology اور summary sections کو مکمل پڑھنے کی سفارش کرتے ہیں، readers باقی document میں اپنی رفتار سے آگے بڑھ سکتے ہیں اور وہ حصے چھوڑ سکتے ہیں جنہیں وہ پہلے ہی سمجھتے ہیں۔
