# 5.2 The Stack :: Digital Data

## गहराई वाली चर्चा

### पहली explicit layer

**Digital Data** Stack की पहली explicit layer है। यह content, state, या resource को represent करता है जब वह computer-readable form में active interface flow में enter कर चुका होता है, लेकिन Model ने अभी उस पर Structure & Semantics apply नहीं किया होता या उसे components, layout, rendering, या presentation में turn नहीं किया होता। यह वह point है जहाँ retained availability ऐसी चीज बनती है जिसके साथ Stack directly काम शुरू कर सकता है।

यह layer explicit है क्योंकि Model अब resource को interface process के part के रूप में describe कर सकता है। जहाँ Data Storage explain करता है कि कोई चीज active flow के बाहर कहाँ persist कर सकती है, वहीं Digital Data उस active representation को explain करता है जिसे read, receive, load, stream, generate, या otherwise Stack के लिए available किया गया है। वह अब सिर्फ कहीं available नहीं है। अब वह ऐसी form में present है जिसे system process कर सकता है।

### Computer-Readable Representation

Digital Data अपनी binary में represent होने और machine द्वारा process होने की ability से define होता है। इस layer पर resource bytes, encoded text, received response, memory buffer, stream, या किसी और machine-readable representation के रूप में held हो सकता है। Exact container उसके role से कम important है: यह interpretation से पहले resource का active form है।

इसका मतलब है कि Digital Data को meaning, structure, या presentation से confuse नहीं करना चाहिए। Bytes की sequence document, image, command, configuration, या audio file contain कर सकती है, लेकिन Layer 7 अभी यह describe नहीं करता कि उस sequence को कैसे understood होना चाहिए। वह सिर्फ establish करता है कि content Stack के अंदर ऐसी form में exist करता है जिसे system access करके next layer को pass कर सकता है।

### Structure and Semantics से पहले

Digital Data सीधे **Layer 6: Structure & Semantics** के ऊपर बैठता है क्योंकि यह उस material को represent करता है जिसे Structure & Semantics interpret करेगा। जब तक वह interpretation नहीं होती, Stack ने अभी representation के भीतर contained rules, relationships, fields, sections, या meanings identify नहीं किए हैं। Resource पहले से किसी format को follow कर सकता है, लेकिन Model ने अभी उस format को apply नहीं किया है।

Stored document अपने format के according पहले से valid हो सकता है, और file पहले से organized content contain कर सकती है, लेकिन Layer 7 उस organization को understood structure के रूप में model नहीं करता। जिस moment Stack rules apply करना शुरू करता है कि representation को कैसे read किया जाना चाहिए, flow Structure & Semantics में move कर चुका होता है। इसलिए Digital Data meaningless नहीं है; वह बस Stack के भीतर अभी interpreted नहीं है।

### Upper Turning Point

Digital Data explicit Stack का upper turning point act करता है। Top-down flow में, यही वह जगह है जहाँ Stack computer-readable representation को ऐसी चीज में transform करना शुरू करता है जिसे user eventually perceive कर सके या जिसके साथ interact कर सके। Flow active representation से शुरू होता है, फिर interpretation, component formation, organization, rendering, windowing, और system delivery से नीचे move करता है।

Bottom-up flow में, Digital Data वह जगह है जहाँ interaction का result फिर से machine-readable बनता है। User action route, handle, और interface के भीतर change में convert हो सकती है। वह change फिर Stack के through ऊपर move कर सकता है जब तक वह Digital Data न बन जाए: एक active representation जिसे retain, transmit, compare, regenerate, या Data Storage में return किया जा सके। इस तरह Layer 7 interface cycle की दोनों directions में participate करता है।

### Digital Data और Domains

Digital Data अक्सर **Symbolic** domain से closely related होता है क्योंकि वह usually किसी specific sensory form के choose होने से पहले exist करता है। Text file, उदाहरण के लिए, बाद में visually display हो सकती है, audibly spoken हो सकती है, किसी और format में translate हो सकती है, या direct presentation के बिना process हो सकती है। Layer 7 पर important fact यह नहीं है कि user उसे eventually कैसे perceive करेगा, बल्कि यह है कि representation Stack के interpret करने के लिए available है।

इसका मतलब यह नहीं है कि Digital Data सिर्फ symbolic हो सकता है। Resource अपनी encoded form में visual, auditory, tactile, या multisensory content contain कर सकता है। हालांकि layer itself उस computer-readable representation को describe करती है जिसे active Stack ने अभी perceivable या interactive result में transform नहीं किया है। Domains identify करते हैं कि कौन सा kind of information handle हो रहा है; Stack identify करता है कि वह information flow में कहाँ है।

### Layer क्यों important है

Digital Data Model को interface work का पहला active step skip करने से रोकता है। इस layer के बिना, Stack storage से सीधे interpretation में move करेगा, जैसे stored resources access होते ही automatically usable structure carry करते हों। Real systems में ऐसा नहीं होता। कोई चीज पहले active machine-readable form में exist करनी चाहिए, तभी उसे parse, validate, organize, adapt, render, या present किया जा सकता है।

Digital Data को Data Storage और Structure & Semantics दोनों से separate रखकर, Model तीन important distinctions preserve करता है। Data Storage active flow के बाहर persistence explain करता है। Digital Data flow के अंदर active computer-readable representation explain करता है। Structure & Semantics उस representation की interpretation explain करता है। इन responsibilities को separate रखने से Stack interface behavior को ज्यादा precision से describe कर सकता है, especially जब वही stored resource एक से ज्यादा तरीकों से read, interpret, transform, या present हो सकता है।
