# 2. Resumo

Para entender como uma interface de usuário funciona, primeiro precisamos definir “_o fluxo de informação_”. Todos os dias, percebam ou não, as pessoas interagem com sistemas de informação — seja um smartphone, computador ou sensor de porta de uma loja (mais sobre isso depois). Em cada sistema, a informação é apresentada, o usuário a interpreta, responde opcionalmente, e então o sistema processa essa resposta. Depois, o sistema apresenta informação novamente, e o ciclo se repete durante toda a interação. O ciclo pode começar em qualquer ponto: a informação pode ter sido apresentada muito antes de o usuário conseguir interpretá-la, ou um usuário pode responder sem que uma informação tenha sido apresentada. Independentemente de quando ou como o fluxo começa, o mesmo ciclo se aplica.

O Modelo CatalystUI é construído em torno desse fluxo. Ele fornece uma estrutura de alto nível para descrever como a informação flui entre um usuário e um sistema de informação, mesmo quando o sistema não se parece com uma interface de usuário tradicional. Em outras palavras, um sensor de porta de uma loja pode parecer “sentir” uma pessoa quase magicamente, mas o fluxo de informação torna o processo simples: o usuário vê a entrada, reconhece o caminho à frente e entra na área de detecção. Esse movimento se torna entrada para o sistema. O sistema o processa, abre a porta como saída perceptível, e o usuário responde passando por ela. Após um curto atraso, o sistema fecha a porta, encerrando a troca até que outra ação reinicie o ciclo.

Junto com o fluxo de informação, uma _interface de usuário_ define como esse fluxo ocorre dentro de um determinado sistema de informação. Ela determina como o sistema aceita entrada, produz saída e permite que o usuário interaja com ele. Como cada sistema tem necessidades diferentes, muitas formas diferentes de descrever e implementar essas interações se desenvolveram ao longo do tempo, incluindo “interfaces humanas” (“HI”), “interfaces homem-máquina” (“HMI”) e “interfaces humano-computador” (“HCI”). Na era moderna da computação, a forma mais familiar dessas interfaces é a “interface gráfica de usuário” (“GUI”).

Quando comparamos as diferentes implementações, um padrão comum começa a surgir. Apesar das diferenças externas, podemos identificar três conceitos que aparecem em todas as interfaces de usuário: 1) “domínios”, que categorizam e organizam dados; 2) “o stack”, que representa e explica dados; e 3) “connectors”, que transformam, modificam e traduzem dados. Cada conceito é útil independentemente, mas juntos eles formam um _sistema_ _reversível_ que pode descrever tanto a interface inteira quanto os processos individuais. É aqui que a força do Modelo CatalystUI fica clara: ao separar a interação em categorização, representação e tradução, ele torna os sistemas de informação mais fáceis de explicar, depurar e entender.
