# 4. Domains

## Visão geral de alto nível

Para descrever o Modelo CatalystUI, precisamos começar pelos domínios. Um _domínio_ descreve a categoria de dados sendo tratada durante uma interação. É o primeiro passo para decompor o fluxo de informação. Ele identifica com que _tipo_ de informação o sistema está trabalhando. Um sensor de porta de loja pode usar pistas visuais ou espaciais para detectar movimento. Um controle de videogame poderia usar informação tátil para produzir feedback háptico. Um alto-falante inteligente pode trabalhar com informação auditiva ao processar fala. Em quase todos os casos, os domínios se alinham à forma como as pessoas percebem o mundo. O Modelo também leva em conta dados antes de chegarem a um sentido específico, bem como dados que abrangem vários sentidos simultaneamente. Como resultado, os sete domínios são definidos como “simbólico”, “visual”, “auditivo”, “tátil”, “olfativo”, “gustativo” e “multissensorial”.

Domínios são úteis porque tornam o fluxo de informação mais fácil de reconhecer, diagnosticar e moldar às necessidades do usuário. Ao identificar a qual domínio a informação pertence, podemos ver com mais clareza o que o sistema está fazendo, o que não está fazendo e quais partes da experiência do usuário podem estar faltando. Isso é especialmente importante para acessibilidade: se uma interface comunica apenas visualmente, o Modelo nos ajuda a reconhecer que formas táteis, auditivas ou outras formas de informação talvez também precisem ser consideradas. Como os domínios descrevem como a informação participa da experiência do usuário, classificar dados em um domínio deve começar perguntando qual papel eles desempenham na interação. Se os dados devem ser vistos, são visuais; se devem ser ouvidos, são auditivos; se devem ser sentidos, são táteis. Se os dados ainda não foram vinculados a um sentido específico, como no caso de um arquivo de texto, são simbólicos. Se várias categorias sensoriais trabalham juntas como uma experiência única, como um jogo que combina imagem, som e vibração do controle, ela é multissensorial.

## O papel dos domínios no Modelo

Depois que os dados foram classificados em um domínio, a interação passa a ter um ponto de partida mais claro. Sabemos que informação o sistema trata, que experiência o usuário terá e se outras formas de comunicação precisam ser consideradas. Com essa categoria estabelecida, o Modelo pode passar de identificar o tipo de dados para descrever como eles se movem pela própria interface.
