# 1. Terminologia

Antes de começarmos, como os leitores podem vir de vários contextos, é importante esclarecer termos comuns usados ao longo da documentação. Embora esses termos possam ser familiares para quem tem experiência em design de interfaces de usuário, muitos serão diferentes de seus significados tradicionais. Eles serão reintroduzidos para refinar, esclarecer e unificar a linguagem usada.

---

### Processo

Um *processo* é algo que aceita uma *entrada*, realiza uma *transformação* e produz uma *saída*.

### Sistema

Um *sistema* é um conjunto organizado de processos, definido pela forma como eles interagem e pela ordem em que são executados.

### Interface

Uma *interface* é um mecanismo que permite que dois sistemas diferentes interajam.

### Sistema de informação

Um *sistema de informação* é uma forma especializada de sistema que trabalha com “dados persistentes”, ou dados que permanecem disponíveis além de um único processo, e permite que um usuário os crie, leia, atualize ou exclua por meio de uma interface ao longo do tempo.

### Computador

Um *computador* é um sistema de informação que trabalha exclusivamente com “dados digitais”, ou dados que podem ser representados em binário e processados por uma máquina.

### Usuário

Um *usuário* é uma pessoa que pode interagir com um sistema de informação.

---

Além disso, o texto reconhece que os termos “dados” e “informação” podem ser defendidos como tendo definições distintas. No entanto, por causa de como são usados no Modelo, trataremos os dois termos como intercambiáveis.
