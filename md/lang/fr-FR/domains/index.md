# 4. Domains

## Vue d’ensemble de haut niveau

Pour décrire le Modèle CatalystUI, nous devons d’abord commencer par les domaines. Un _domaine_ décrit la catégorie de données manipulée pendant une interaction. C’est la première étape pour décomposer le flux d’information. Il identifie le _type_ d’information avec lequel le système travaille. Un capteur de porte de magasin peut utiliser des indices visuels ou spatiaux pour détecter un mouvement. Une manette de jeu pourrait utiliser des informations tactiles pour produire un retour haptique. Une enceinte intelligente peut travailler avec des informations auditives lorsqu’elle traite la parole. Dans presque tous les cas, les domaines s’alignent sur la manière dont les personnes perçoivent le monde. Le Modèle tient également compte des données avant qu’elles n’atteignent un sens précis, ainsi que des données qui couvrent simultanément plusieurs sens. Par conséquent, les sept domaines sont définis comme « symbolique », « visuel », « auditif », « tactile », « olfactif », « gustatif » et « multisensoriel ».

Les domaines sont utiles parce qu’ils rendent le flux d’information plus facile à reconnaître, à diagnostiquer et à adapter aux besoins de l’utilisateur. En identifiant le domaine auquel appartient l’information, nous pouvons voir plus clairement ce que le système fait, ce qu’il ne fait pas, et quelles parties de l’expérience utilisateur peuvent manquer. C’est particulièrement important pour l’accessibilité : si une interface ne communique que visuellement, le Modèle nous aide à reconnaître que des formes tactiles, auditives ou autres d’information doivent peut-être aussi être prises en compte. Comme les domaines décrivent la façon dont l’information participe à l’expérience de l’utilisateur, classer des données dans un domaine doit d’abord commencer par demander quel rôle elles jouent dans l’interaction. Si les données sont destinées à être vues, elles sont visuelles ; si elles sont destinées à être entendues, elles sont auditives ; si elles sont destinées à être ressenties, elles sont tactiles. Si les données ne sont pas encore engagées dans un sens précis, comme dans le cas d’un fichier texte, elles sont symboliques. Si plusieurs catégories sensorielles fonctionnent ensemble comme une seule expérience, par exemple un jeu vidéo combinant visuels, son et vibration de manette, elles sont multisensorielles.

## Le rôle des domaines dans le Modèle

Une fois que les données ont été classées dans un domaine, l’interaction dispose d’un point de départ plus clair. Nous savons quelle information le système traite, quelle expérience l’utilisateur aura, et si d’autres formes de communication doivent être envisagées. Une fois cette catégorie établie, le Modèle peut passer de l’identification du type de données à la description de la manière dont elles se déplacent à travers l’interface elle-même.
