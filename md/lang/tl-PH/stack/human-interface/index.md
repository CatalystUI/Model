# 5.9 The Stack :: Human Interface

## In-Depth Discussion

### The Implied Human Boundary

Ang **Human Interface** ang implied lower boundary ng Stack. Kinakatawan nito ang user: ang taong tumatanggap ng perceivable output mula sa system at gumagawa ng actions na maaaring maging interaction input. Sa mas simpleng salita, ikaw ito.

### The Recipient of Perceivable Output

Ang output ng computer ay walang saysay bilang interface kung walang makaka-perceive nito. Ang screen, speaker, vibration, scent, o iba pang output ay nagiging meaningful lamang kapag may user na nakakaintindi o nakakaranas nito. Dito nagtatapos ang top-down flow.

### The Source of Interaction

Dito rin nagsisimula ang bottom-up flow. Kapag nag-click, nag-type, nagsalita, humawak, gumalaw, o tumugon ang user, nagkakaroon ng action na maaaring iproseso ng system bilang interaction data. Ang intent ng tao ang dahilan kung bakit may kailangang baguhin o gawin ang system.

### Why the Layer Is Implied

Implied ang layer na ito dahil hindi direktang nirerepresent o kinokontrol ng CatalystUI ang tao. Hindi ito software object. Ngunit kailangan itong kilalanin dahil ang buong Model ay umiikot sa communication sa pagitan ng tao at information system.

### Perception and Intent

Dalawang bagay ang mahalaga sa Human Interface: perception at intent. Kailangang maabot ng output ang perception ng user, at kailangang maipahayag ng user ang intent pabalik sa system. Kapag nabigo ang alinman dito, mahina ang interface.

### Relationship to Systems

Ang System ang pinakamalapit na explicit layer sa user. Ito ang naghahatid ng output at unang tumatanggap ng action. Ngunit ang tao ang tunay na dahilan kung bakit may interface sa una pa lang.

### Accessibility and Human Variation

Hindi pare-pareho ang kakayahan, senses, context, at needs ng bawat user. Kaya mahalaga ang accessibility sa Model. Ang mabuting interface ay naghahanap ng paraan upang mapanatili ang meaning kahit magbago ang sensory channel o interaction method.

### Why the Layer Matters

Kung aalisin ang Human Interface, mawawala ang dahilan ng buong Stack. Ang computing ay hindi lang pagproseso ng bits; ito ay pagdadala ng meaning sa tao at pagtanggap ng intent mula sa tao.
