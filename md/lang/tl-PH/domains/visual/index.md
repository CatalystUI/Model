# 4.2 Domains :: Visual

## In-Depth Discussion

Ang **visual** domain ay naglalarawan ng data na hinubog upang makita. Kabilang dito ang text na nakalagay sa screen, mga icon, larawan, video, kulay, laki, spacing, animation, at iba pang output na nauunawaan sa pamamagitan ng paningin.

### Understanding Visual Data

Ang visual data ay hindi lang basta pixels. Ang pixels ay maaaring literal na paraan ng paglabas nito, ngunit ang visual meaning ay nasa relasyon ng mga hugis, kulay, posisyon, contrast, at galaw. Ang isang pulang bilog ay maaaring dekorasyon, warning, button, status indicator, o bahagi ng larawan depende sa context.

### Visual Meaning

Mabilis makita ng tao ang maraming visual relationships nang sabay-sabay. Maaari nating mapansin ang hierarchy, alignment, grouping, at emphasis sa isang tingin. Dahil dito, mahalaga sa visual domain ang layout, spacing, contrast, scale, at consistency. Ang maling placement o mahirap basahing contrast ay maaaring magpabago sa kahulugan kahit tama ang underlying data.

### Visual Data and Accessibility

Hindi lahat ng user ay pareho ang visual perception. Maaaring may low vision, color blindness, motion sensitivity, o paggamit ng assistive technologies. Kaya dapat isipin ang visual data bilang isang presentation domain na maaaring kailanganing isalin sa auditory, tactile, o symbolic alternatives.

### Visual Data in Broader Experiences

Kadalasang bahagi ang visual data ng multisensory experience. Ang isang app window ay maaaring magpakita ng animation habang may tunog at haptic feedback. Sa CatalystUI, nananatiling mahalaga ang pagkilala sa visual domain dahil ipinapakita nito kung aling bahagi ng meaning ang nakabatay sa paningin.
