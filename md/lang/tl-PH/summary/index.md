# 2. Buod

## Ang Daloy ng Impormasyon

> **Tandaan:** Ang seksyong ito ay nagsisilbing high-level overview ng Model. Ang kasunod na dokumentasyon ay magbibigay ng per-topic summaries at in-depth discussions.

Upang maunawaan kung paano gumagana ang isang user interface, kailangan muna nating tukuyin ang “_daloy ng impormasyon_.” Araw-araw, napakaraming beses tayong nakikipag-ugnayan sa mga information system: smartphone, computer, game console, website, o kahit sensor ng pintuan sa tindahan. Sa bawat system, may impormasyong ipinapakita o ipinaparating, naiintindihan ito ng user, maaaring tumugon ang user, at pagkatapos ay pinoproseso ng system ang tugon. Pagkatapos nito, muling maglalabas ang system ng impormasyon, at uulit ang cycle.

Maaaring magsimula ang cycle sa kahit anong punto. Minsan, matagal nang ipinapakita ang impormasyon bago ito mapansin ng user. Minsan naman, unang kumikilos ang user at saka pa lang tumutugon ang system. Anuman ang simula, pareho pa rin ang pangunahing pattern: information output, human perception, interaction input, at system processing.

Dito nakasentro ang CatalystUI Model. Nagbibigay ito ng paraan upang ilarawan kung paano gumagalaw ang impormasyon sa pagitan ng user at information system, kahit hindi ito mukhang tradisyonal na graphical interface. Halimbawa, ang automatic door sensor ay maaaring mukhang “nakakaramdam” ng tao, ngunit sa Model, malinaw ang proseso: nakikita ng user ang daanan, lumalapit siya, nagiging input ang paggalaw niya, pinoproseso ito ng system, at nagbubukas ang pinto bilang perceivable output.

Kapag inihambing ang iba’t ibang uri ng interface, lumilitaw ang tatlong pangunahing konsepto. Una, may **Domains**, na kumakategorya sa uri ng data. Ikalawa, may **Stack**, na naglalarawan kung saan at paano kinakatawan ang data. Ikatlo, may **Connectors**, na nagsasalin at nagbabago ng data sa pagitan ng mga bahagi. Magkakasama, bumubuo ang mga ito ng reversible system para maunawaan ang buong palitan ng impormasyon sa user interface.
