# Panimula

Ang CatalystUI Model (“Model”) ay isang pangkalahatang paraan ng pagtingin sa mga pangunahing prinsipyo ng disenyo ng user interface. Sa panahon kung kailan maraming framework ang nakatuon lamang sa makikitid at espesyalisadong problema, umaatras ang CatalystUI at tinitingnan mismo ang konsepto ng interface: paano ba talaga nagpapalitan ng impormasyon ang tao at ang information system?

Mula sa pananaw na ito, mas madaling makita ang mga paulit-ulit na pattern sa iba’t ibang solusyon, maunawaan kung saan sila malakas o limitado, at gamitin ang kaalamang iyon upang bumuo ng isang modelong sumasaklaw sa buong proseso ng interaksyon sa pagitan ng end user at ng system.

Inayos ang dokumentasyong ito sa tatlong antas ng pag-unawa: mataas na overview, per-topic summary, at in-depth discussion. Mainam basahin nang buo ang Terminology at Summary, pagkatapos ay maaari nang lumipat-lipat ang mambabasa ayon sa kailangan. Ang layunin ay hindi gawing mas kumplikado ang UI, kundi gawing mas malinaw ang nangyayari sa likod ng bawat interaksyon.
