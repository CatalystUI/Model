# 4.7 Domains :: Multisensory

## Ausführliche Besprechung

Die **multisensorische** Domain beschreibt Daten, die als Teil einer einheitlichen Erfahrung für mehr als einen Sinn geformt sind. Es geht nicht nur darum, dass mehrere Ausgaben im selben System vorhanden sind. Es geht um den Punkt, an dem verschiedene sensorische Formen verbunden, koordiniert, geroutet oder gemeinsam geliefert werden, sodass der Benutzer sie als „*eine Sache*“ empfängt.

Diese Unterscheidung ist wichtig, weil ein System mehrere Arten von Ausgabe enthalten kann, ohne wirklich multisensorisch zu sein. Ein Programm kann an einer Stelle ein Bild anzeigen und anderswo einen Ton abspielen, aber wenn diese Ausgaben nicht zusammenhängen, bleiben sie getrennte Kommunikationsformen. Multisensorische Daten entstehen, wenn diese Formen absichtlich miteinander verbunden oder gleichzeitig präsentiert werden. Ein Video mit synchronisiertem Audio, ein Spielereignis, das Aufprallgeräusch mit physischem Feedback verbindet, oder ein Gerät, das koordinierte Ausgabe über getrennte Anzeige- und Lautsprecherpfade sendet, kann zu dieser Domain gehören, weil die Erfahrung von der Beziehung zwischen den Ausgaben abhängt.

Multisensorische Daten erscheinen oft an dem Punkt, an dem Informationen nicht mehr als eine isolierte Repräsentation behandelt werden, sondern als koordinierte Auslieferung. Daten können zu einem Stream zusammengeführt, auf Ausgaben verteilt oder für mehrere Geräte gleichzeitig vorbereitet werden. Entscheidend ist nicht, dass alles durch ein Kabel, eine Datei oder ein Objekt läuft. Entscheidend ist, dass der Benutzer das Ergebnis als ein bedeutungsvolles Ereignis empfängt.

### Multisensorische Daten verstehen

Eine hilfreiche Möglichkeit, multisensorische Daten zu verstehen, besteht darin, **Komposition**, **Synchronisierung** und **Routing** zu betrachten.

**Komposition** beschreibt, wie verschiedene Ausgabeformen zusammengebracht werden. In einem Videoanruf können Sprache, Gesichtsbewegung, Untertitel und Schnittstellenfeedback alle zur selben Erfahrung beitragen. Keines dieser Teile ersetzt die anderen vollständig. Ihre Bedeutung wird stärker, weil sie zu einem kommunikativen Ganzen zusammengesetzt werden.

**Synchronisierung** beschreibt, wie diese Ausgaben über die Zeit miteinander verbunden bleiben. Ein Ton, der zu spät eintrifft, eine Vibration, die erst nach dem Ereignis ausgelöst wird, oder Untertitel, die der Sprache hinterherhinken, können die Erfahrung defekt wirken lassen, selbst wenn jede einzelne Ausgabe noch funktioniert. Multisensorische Daten hängen vom Timing ab, weil die Beziehung zwischen Signalen oft Teil der Bedeutung ist.

**Routing** beschreibt, wie eine einheitliche Erfahrung über getrennte Pfade geliefert werden kann. Ein System kann einen Teil der Ausgabe an ein Display senden, einen anderen an Lautsprecher und einen weiteren an ein haptisches Gerät. Diese Pfade können physisch getrennt sein, aber der Benutzer versteht sie dennoch als eine Interaktion, wenn sie richtig koordiniert sind. Routing ist wichtig, weil multisensorische Daten in der Bedeutung oft einheitlich bleiben müssen, während sie in der Lieferung aufgeteilt werden.

### Multisensorische Bedeutung

Multisensorische Ausgabe drückt Bedeutung durch Beziehung aus. Ein Ton kann bestätigen, was der Benutzer sieht. Eine Vibration kann dem Gewicht geben, was der Benutzer hört. Ein Untertitel kann Informationen bewahren, die sonst in Sprache verloren gingen. Jeder Teil hat seine eigene sensorische Form, aber die größere Bedeutung entsteht daraus, wie die Teile zusammenarbeiten.

Das unterscheidet multisensorisches Design davon, einfach Effekte hinzuzufügen. Ein Ton an einem Button ist nicht automatisch bedeutungsvoll. Eine Vibration an einer Warnung ist nicht automatisch hilfreich. Eine visuelle Animation zusammen mit Audio kann eine Interaktion stärken, wenn beide dasselbe Ereignis kommunizieren, kann aber auch Verwirrung erzeugen, wenn sie Unterschiedliches nahelegen. Die Domain ist nützlich, weil sie fragt, ob die Ausgaben zusammenarbeiten oder nur nebeneinander existieren.

Multisensorische Daten können Bedeutung auch robuster tragen als ein einzelner sensorischer Pfad. Wenn eine Ausgabe verpasst wird, kann eine andere noch einen Teil der Nachricht bewahren. Wenn der Benutzer sich nicht auf Sehen verlassen kann, kann Klang die wichtige Information tragen. Wenn die Umgebung laut ist, können Berührung oder sichtbare Struktur sie stattdessen tragen. Eine gut gestaltete multisensorische Erfahrung verstreut Bedeutung nicht zufällig; sie verteilt Bedeutung mit Absicht.

### Multisensorische Daten und Barrierefreiheit

Die multisensorische Domain ist für Barrierefreiheit besonders wichtig, weil sie hilft zu erkennen, ob Bedeutung über verschiedene Wahrnehmungsformen hinweg bewahrt wird. Wenn mehrere Ausgaben gut koordiniert sind, hat der Benutzer mehr als eine Möglichkeit zu verstehen, was passiert ist. Wenn sie schlecht koordiniert sind, kann das System oberflächlich barrierefrei erscheinen und dennoch wichtige Bedeutung in einem einzigen sensorischen Pfad einschließen.

Eine Benachrichtigung, die visuell erscheint, hörbar klingt und physisches Feedback liefert, kann dasselbe Ereignis auf mehrere Arten kommunizieren. Das kann hilfreich sein, aber nur, wenn jede Form bedeutungsvoll und angemessen ist. Wenn der Ton Informationen trägt, die die visuelle Ausgabe nicht trägt, oder die visuelle Ausgabe Details enthält, auf die die anderen Ausgaben keinen Zugriff haben, bleibt die Erfahrung möglicherweise unausgewogen. Multisensorisches Design sollte Absicht bewahren und nicht nur Effekte duplizieren.

Hier muss das System auch die Kontrolle des Benutzers respektieren. Manche Benutzer brauchen mehr Ausgabe über einen Sinn und weniger über einen anderen. Andere deaktivieren Klang, reduzieren Bewegung, vermeiden Vibration oder verlassen sich auf Untertitel. Eine multisensorische Erfahrung ist am stärksten, wenn sie sich anpassen kann, ohne die Bedeutung zu verlieren, die die Erfahrung überhaupt kohärent gemacht hat.

### Multisensorische Daten in umfassenderen Systemen

Multisensorische Daten erscheinen oft in Systemen, in denen Informationen über mehrere Kanäle gleichzeitig geliefert werden müssen. Medienwiedergabe kann bewegte Bilder und Klang zu einem Stream verbinden. Ein Simulator kann visuelle, auditive und physische Rückmeldung koordinieren, um ein Ereignis aus der realen Welt darzustellen. Eine Betriebsumgebung kann verschiedene Arten von Ausgabe an verschiedene Geräte leiten und dem Benutzer dennoch eine einheitliche Interaktion präsentieren.

Diese Beispiele zeigen, warum multisensorische Daten nicht als lose Sammlung getrennter Domains behandelt werden können. Sobald Ausgaben synchronisiert, komponiert oder geroutet werden, wird die Beziehung zwischen ihnen Teil der Information. Das System fragt nicht mehr nur: „Was soll gesehen werden?“ oder „Was soll gehört werden?“ Es fragt, wie mehrere Wahrnehmungsformen zusammenarbeiten sollen, damit der Benutzer ein Ereignis versteht.

Das erklärt auch, warum multisensorische Daten oft schwer gut zu gestalten sind. Jede Ausgabe hat ihre eigenen Grenzen, ihr eigenes Timing, ihre Liefermethode und ihre Benutzererwartung. Sie zu kombinieren erfordert mehr, als dieselbe Nachricht überallhin zu senden. Es erfordert zu entscheiden, welcher Teil der Bedeutung in welche Form gehört, wie diese Formen verbunden bleiben und was geschehen soll, wenn eine von ihnen nicht verfügbar ist.

### Multisensorische Daten und der Zweck von Domains

Die multisensorische Domain hilft, das Domain-Modell zu vervollständigen, indem sie beschreibt, was passiert, wenn sensorische Kommunikation koordiniert wird. Symbolische Daten geben dem System eine Möglichkeit, Bedeutung als Repräsentation zu halten. Die einzelnen sensorischen Domains erklären, wie diese Bedeutung auf bestimmte Weisen wahrnehmbar werden kann. Multisensorische Daten erklären, wie diese wahrnehmbaren Formen zu einer größeren Erfahrung kombiniert werden können.

Das ist ein Grund, warum diese Domain notwendig ist. Ohne sie müsste jede komplexe Ausgabe nur als getrennte sensorische Teile beschrieben werden. Das würde den Kern vieler realer Interaktionen verfehlen. Ein Film wird nicht als isolierte Bilder plus isolierte Klänge erlebt. Ein Aufprall in einem Spiel wird nicht immer als getrennte Animation, getrenntes Geräusch und getrennte Vibration verstanden. Der Benutzer empfängt die Beziehung zwischen ihnen.

Kurz gesagt beschreibt die multisensorische Domain Informationen, die zu koordinierter sensorischer Ausgabe geformt sind. Sie hilft zu erklären, wie Systeme Daten komponieren, synchronisieren und routen, sodass mehrere Wahrnehmungsformen eine zusammenhängende Bedeutung tragen können. Wenn multisensorische Daten gut behandelt werden, empfängt der Benutzer nicht nur mehrere Ausgaben zugleich; er empfängt eine einheitliche Erfahrung, die Bedeutung über die beteiligten Sinne hinweg bewahrt.
