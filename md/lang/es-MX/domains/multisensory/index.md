# 4.7 Domains :: Multisensory

## Explicación en profundidad

El dominio **multisensorial** describe datos moldeados para más de un sentido como parte de una experiencia unificada. No es simplemente la presencia de varias salidas en el mismo sistema. Es el punto en el que distintas formas sensoriales se unen, coordinan, enrutan o entregan juntas para que el usuario las reciba como “*una sola cosa*”.

Esa distinción importa porque un sistema puede contener varios tipos de salida sin ser significativamente multisensorial. Un programa puede mostrar una imagen en un lugar y reproducir un sonido en otro, pero si esas salidas no están relacionadas, siguen siendo formas separadas de comunicación. Los datos multisensoriales aparecen cuando esas formas se vinculan intencionalmente o se presentan al mismo tiempo. Un vídeo con audio sincronizado, un evento de juego que combina sonido de impacto con retroalimentación física, o un dispositivo que envía salida coordinada por rutas separadas de pantalla y altavoces pueden pertenecer a este dominio porque la experiencia depende de la relación entre las salidas.

Los datos multisensoriales suelen aparecer cerca del punto en que la información ya no se maneja como una sola representación aislada, sino como una entrega coordinada. Los datos pueden fusionarse en un flujo, dividirse entre salidas o prepararse para varios dispositivos a la vez. La característica importante no es que todo viaje por un solo cable, archivo u objeto. La característica importante es que el usuario recibe el resultado como un evento significativo.

### Comprender los datos multisensoriales

Una forma útil de entender los datos multisensoriales es considerar **composición**, **sincronización** y **enrutamiento**.

**Composición** describe cómo se reúnen distintas formas de salida. En una videollamada, el habla, el movimiento facial, los subtítulos y la retroalimentación de la interfaz pueden contribuir a la misma experiencia. Ninguna de estas piezas sustituye por completo a las demás. Su significado se vuelve más fuerte porque se componen en un todo comunicativo.

**Sincronización** describe cómo esas salidas permanecen relacionadas en el tiempo. Un sonido que llega demasiado tarde, una vibración que se activa después de que el evento haya pasado, o unos subtítulos que se retrasan respecto al habla pueden hacer que la experiencia parezca rota aunque cada salida individual siga funcionando. Los datos multisensoriales dependen del tiempo porque la relación entre señales a menudo forma parte del significado.

**Enrutamiento** describe cómo una experiencia unificada puede entregarse por rutas separadas. Un sistema puede enviar una parte de la salida a una pantalla, otra a altavoces y otra a un dispositivo háptico. Esas rutas pueden estar físicamente separadas, pero el usuario sigue entendiéndolas como una sola interacción cuando están coordinadas correctamente. El enrutamiento importa porque los datos multisensoriales a menudo deben permanecer unificados en significado mientras se dividen en la entrega.

### Significado multisensorial

La salida multisensorial expresa significado mediante relación. Un sonido puede confirmar lo que el usuario ve. Una vibración puede dar peso a lo que el usuario oye. Un subtítulo puede conservar información que de otro modo se perdería en el habla. Cada parte tiene su propia forma sensorial, pero el significado mayor viene de cómo trabajan juntas las partes.

Esto hace que el diseño multisensorial sea distinto de simplemente añadir efectos. Un sonido añadido a un botón no es automáticamente significativo. Una vibración añadida a una alerta no es automáticamente útil. Una animación visual emparejada con audio puede fortalecer una interacción cuando ambas comunican el mismo evento, pero también puede crear confusión si sugieren cosas distintas. El dominio se vuelve útil porque pregunta si las salidas cooperan o simplemente coexisten.

Los datos multisensoriales también pueden transportar significado con más resiliencia que una sola ruta sensorial. Si se pierde una salida, otra puede conservar parte del mensaje. Si el usuario no puede depender de la vista, el sonido puede transportar la información importante. Si el entorno es ruidoso, el tacto o la estructura visible pueden transportarla en su lugar. Una experiencia multisensorial bien diseñada no dispersa significado al azar; distribuye significado con propósito.

### Datos multisensoriales y accesibilidad

El dominio multisensorial es especialmente importante para la accesibilidad porque ayuda a identificar si el significado se conserva a través de distintas formas de percepción. Cuando varias salidas están bien coordinadas, el usuario tiene más de una forma de entender qué ocurrió. Cuando están mal coordinadas, el sistema puede parecer accesible en la superficie y aun así dejar significado importante atrapado en una sola ruta sensorial.

Una notificación que aparece visualmente, suena de forma audible y proporciona retroalimentación física puede comunicar el mismo evento de varias maneras. Eso puede ser útil, pero solo si cada forma es significativa y apropiada. Si el sonido transporta información que la salida visual no contiene, o la salida visual contiene detalles a los que las otras salidas no pueden acceder, la experiencia puede seguir siendo desigual. El diseño multisensorial debería preservar la intención, no solo duplicar efectos.

Aquí también el sistema debe respetar el control del usuario. Algunos usuarios pueden necesitar más salida por un sentido y menos por otro. Otros pueden desactivar el sonido, reducir el movimiento, evitar la vibración o depender de subtítulos. Una experiencia multisensorial es más fuerte cuando puede adaptarse sin perder el significado que hacía coherente la experiencia en primer lugar.

### Datos multisensoriales en sistemas más amplios

Los datos multisensoriales suelen aparecer en sistemas donde la información debe entregarse por varios canales a la vez. La reproducción multimedia puede combinar imágenes en movimiento y sonido en un solo flujo. Un simulador puede coordinar elementos visuales, audio y retroalimentación física para representar un evento del mundo real. Un entorno operativo puede enrutar distintos tipos de salida a distintos dispositivos y seguir presentando una interacción unificada al usuario.

Estos ejemplos muestran por qué los datos multisensoriales no pueden tratarse como una colección suelta de dominios separados. Una vez que las salidas se sincronizan, componen o enrutan juntas, la relación entre ellas se vuelve parte de la información. El sistema ya no pregunta solo: “¿Qué debería verse?” o “¿Qué debería oírse?”. Pregunta cómo varias formas de percepción deberían trabajar juntas para que el usuario entienda un evento.

Esto también explica por qué los datos multisensoriales suelen ser difíciles de diseñar bien. Cada salida tiene sus propios límites, tiempo, método de entrega y expectativa del usuario. Combinarlas exige más que enviar el mismo mensaje a todas partes. Exige decidir qué parte del significado pertenece a cada forma, cómo esas formas permanecen conectadas y qué debería ocurrir si una de ellas no está disponible.

### Datos multisensoriales y el propósito de los dominios

El dominio multisensorial ayuda a completar el modelo de dominios al describir qué ocurre cuando la comunicación sensorial se vuelve coordinada. Los datos simbólicos dan al sistema una forma de mantener significado como representación. Los dominios sensoriales individuales explican cómo ese significado puede volverse perceptible de formas específicas. Los datos multisensoriales explican cómo esas formas perceptibles pueden combinarse en una experiencia mayor.

Esta es una de las razones por las que el dominio es necesario. Sin él, cada salida compleja tendría que describirse solo como partes sensoriales separadas. Eso perdería el punto de muchas interacciones reales. Una película no se experimenta como imágenes aisladas más sonidos aislados. Un impacto en un juego no siempre se entiende como una animación separada, un ruido separado y una vibración separada. El usuario recibe la relación entre ellos.

En resumen, el dominio multisensorial describe información moldeada en salida sensorial coordinada. Ayuda a explicar cómo los sistemas componen, sincronizan y enrutan datos para que varias formas de percepción puedan transportar un significado conectado. Cuando los datos multisensoriales se manejan bien, el usuario no recibe simplemente varias salidas a la vez; recibe una experiencia unificada que preserva significado a través de los sentidos involucrados.
