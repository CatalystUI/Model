# 4.2 Domain :: Visual

## Pembahasan Mendalam

### Memahami Data Visual

Data **Visual** adalah data yang dirancang untuk dipersepsikan melalui penglihatan. Ini mencakup warna, bentuk, gambar, ikon, video, tata letak, ukuran, kedalaman, kontras, posisi, dan perubahan visual lain yang memberi informasi kepada pengguna.

Dalam banyak pembahasan komputer modern, antarmuka pengguna sering disamakan dengan visual. CatalystUI sengaja memperluas pandangan itu, tetapi domain Visual tetap sangat penting. Banyak sistem komputer berkomunikasi terutama melalui layar, dan layar menyusun informasi dengan cara yang sangat bergantung pada persepsi manusia terhadap ruang dan bentuk.

### Makna Visual

Makna visual tidak hanya berasal dari piksel. Piksel dapat menyusun gambar, tetapi pengguna memahami gambar karena bentuk, pola, posisi, dan relasi di antara elemen-elemen itu. Sebuah tombol terlihat dapat ditekan bukan hanya karena warnanya, tetapi karena bentuk, bayangan, label, posisi, dan kebiasaan pengguna terhadap pola visual serupa.

Dalam CatalystUI, data visual dapat muncul pada beberapa lapisan Stack. Komponen dapat memiliki ukuran dan warna. Layout dapat menentukan posisi. Graph dan Frame dapat menentukan batas. Renderer mengubah representasi itu menjadi bentuk output visual yang siap dikirimkan. Window menyediakan konteks pengiriman, dan System membawa output itu ke perangkat seperti monitor.

### Data Visual dan Aksesibilitas

Karena penglihatan manusia sangat bervariasi, data visual harus dipahami sebagai satu jalur persepsi, bukan satu-satunya jalur. Warna, kontras, ukuran teks, gerakan, kepadatan informasi, dan tata letak dapat membantu sebagian pengguna tetapi menyulitkan pengguna lain.

Representasi visual yang baik sering perlu didampingi informasi simbolik atau auditory. Ikon dapat memiliki label. Grafik dapat memiliki deskripsi. Warna peringatan dapat didukung oleh teks atau suara. Dengan begitu, makna tidak hilang ketika pengguna tidak dapat mengakses satu unsur visual tertentu.

### Data Visual dalam Pengalaman yang Lebih Luas

Data visual sering bekerja bersama domain lain. Video dapat menggabungkan visual dan auditory. Sistem permainan dapat menggabungkan visual, suara, dan haptik. Aplikasi navigasi dapat menampilkan peta sekaligus memberi instruksi suara. Ketika beberapa saluran digabung menjadi pengalaman terpadu, model dapat menggambarkannya sebagai Multisensory.

Domain Visual membantu CatalystUI membahas semua bentuk ini tanpa menganggap bahwa visual adalah keseluruhan antarmuka. Visual adalah satu domain kuat di antara beberapa domain lain yang dapat membawa makna kepada manusia.
