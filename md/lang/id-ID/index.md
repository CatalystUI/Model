# Pengantar

Selamat datang di CatalystUI, sebuah model antarmuka pengguna yang lahir dari pengamatan panjang terhadap cara manusia dan sistem informasi saling berkomunikasi. CatalystUI tidak memperlakukan antarmuka pengguna hanya sebagai kumpulan tombol, jendela, teks, gambar, atau suara. Model ini memandang antarmuka sebagai keseluruhan proses: data disimpan, diterjemahkan, disusun, disiapkan, dirender, dikirimkan melalui sistem, lalu akhirnya dipersepsikan dan ditanggapi oleh pengguna.

Dokumentasi ini menjelaskan model tersebut melalui beberapa bagian utama. Bagian terminologi memberikan dasar bahasa yang digunakan di seluruh dokumen. Bagian ringkasan menjelaskan aliran informasi secara umum. Bagian referensi menyediakan bentuk ringkas yang mudah ditinjau kembali. Bagian domain menjelaskan sifat sensoris data. Bagian Stack menjelaskan lapisan-lapisan yang dilewati data. Bagian konektor menjelaskan bagaimana data berpindah dari satu lapisan ke lapisan berikutnya. Bagian interaksi menjelaskan bagaimana tindakan manusia masuk kembali ke dalam sistem.

Tujuan utamanya sederhana: memberikan cara yang konsisten untuk memahami setiap bentuk antarmuka, baik itu aplikasi grafis, pemutar audio, perangkat haptik, sensor pintu, terminal teks, sistem tertanam, atau bentuk interaksi lain yang belum biasa kita anggap sebagai “UI.”
