# 4.7 Domains :: Multisensory

## In-Depth Discussion

**multisensory** domain এমন data describe করে যা unified experience-এর অংশ হিসেবে একাধিক sense-এর জন্য shaped। এটি একই system-এ multiple output থাকা মাত্র নয়। বরং তখনই multisensory বলা যায়, যখন বিভিন্ন sensory form join, coordinate, route, বা together deliver হয় যাতে user সেগুলোকে “*একটি জিনিস*” হিসেবে receive করে।

একটি program এক জায়গায় image দেখাতে পারে এবং অন্য জায়গায় unrelated sound বাজাতে পারে—এটি meaningfully multisensory নয়। কিন্তু synchronized audio সহ video, impact sound + controller vibration সহ game event, অথবা display ও speaker path দিয়ে coordinated output পাঠানো device multisensory domain-এ পড়তে পারে কারণ experience outputs-এর relationship-এর উপর নির্ভর করে।

### Understanding Multisensory Data

Multisensory data বোঝার জন্য **composition**, **synchronization**, এবং **routing** গুরুত্বপূর্ণ। **Composition** বলে output-এর ভিন্ন form কীভাবে একত্র হয়। video call-এ speech, facial movement, captions, এবং interface feedback একই communication-এ contribute করতে পারে।

**Synchronization** বলে outputগুলো time-এর সঙ্গে related থাকে কীভাবে। sound late হলে, vibration event পেরিয়ে যাওয়ার পরে এলে, captions speech থেকে পিছিয়ে পড়লে experience broken লাগে। timing নিজেই meaning-এর অংশ হতে পারে।

**Routing** বলে unified experience কীভাবে separate path দিয়ে deliver হয়। এক অংশ display-তে, অন্য অংশ speakers-এ, আরেক অংশ haptic device-এ যেতে পারে। paths আলাদা হলেও coordination ঠিক থাকলে user এক interaction হিসেবে বোঝে।

### Multisensory Meaning and Accessibility

Multisensory output relationship-এর মাধ্যমে meaning express করে। sound visual event confirm করতে পারে, vibration heard event-কে weight দিতে পারে, caption speech-এর information preserve করতে পারে। কিন্তু effect add করলেই meaningful হয় না। outputs cooperate করছে নাকি শুধু coexist করছে—এই প্রশ্নটাই domain-কে useful করে।

Accessibility-তে multisensory domain বিশেষ গুরুত্বপূর্ণ। একই event visual, auditory, এবং tactile ভাবে communicate হলে user একাধিক path দিয়ে বুঝতে পারে। কিন্তু প্রতিটি form meaningful ও appropriate হতে হবে। user sound disable করতে পারেন, motion reduce করতে পারেন, vibration avoid করতে পারেন, বা captions-এর উপর নির্ভর করতে পারেন। strong multisensory design adapt করতে পারে কিন্তু core meaning হারায় না।

### Multisensory Data in the Model

Symbolic data meaning hold করে, individual sensory domains meaning perceivable করে, আর multisensory domain ব্যাখ্যা করে কীভাবে perceivable forms এক unified experience হিসেবে combine হয়। Movie isolated images plus isolated sounds নয়; game impact আলাদা animation, noise, vibration-এর যোগফল মাত্র নয়। user তাদের relationship receive করে। সংক্ষেপে, multisensory domain coordinated sensory output describe করে।
