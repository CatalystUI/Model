# 5.8 The Stack :: Systems

## بحث عمیق

### پایین‌ترین لایه صریح

**Systems** پایین‌ترین لایه صریح Stack هستند. این لایه محیط رایانشی را نشان می‌دهد که سرویس‌ها، دستگاه‌ها و عملیات زیربنایی لازم برای تحویل خروجی و دریافت interaction را فراهم می‌کند. Layer 2 زمینه bounded را تعریف می‌کند؛ Layer 1 جهان وسیع‌تری را نشان می‌دهد که آن زمینه را ممکن می‌سازد.

System نباید فقط به‌عنوان سیستم‌عامل دسکتاپ فهمیده شود. در مدل CatalystUI، system مجموعه سازمان‌یافته‌ای از فرایندها و قابلیت‌های پلتفرم است که رابط را در زمان اجرا پشتیبانی می‌کند. این می‌تواند سیستم‌عامل سنتی، محیط embedded، console، runtime مرورگر، پلتفرم سخت‌افزاری یا زمینه رایانشی مدیریت‌شده دیگری باشد.

### محیط اجرا

System layer محیط اجرای اطراف Stack صریح را فراهم می‌کند. این لایه ممکن است دسترسی سخت‌افزار، دستگاه‌های ورودی، دستگاه‌های خروجی، driverها، permissionها، scheduling، memory، files، processes، windows، channels یا سرویس‌های سطح پلتفرم را مدیریت کند. جزئیات در هر پیاده‌سازی متفاوت است، اما نقش مفهومی یکی است: system اجازه می‌دهد رابط با قابلیت‌های واقعی ماشین یا سیستم اطلاعاتی ارتباط بگیرد.

### تفاوت با Window

Window زمینه‌ای مشخص و bounded برای رابط است. System محیطی است که آن زمینه را ایجاد، مالکیت، شناسایی، محدود و سرویس‌دهی می‌کند. Window نقطه اتصال مشخص را فراهم می‌کند؛ system جهان عملیاتی پشت آن نقطه را فراهم می‌سازد.

### خروجی و ورودی واقعی

در مسیر بالا به پایین، خروجی renderشده از window به system می‌رسد تا از طریق display، speaker، motor، device channel یا مسیر دیگری به کاربر برسد. در مسیر پایین به بالا، system نخستین جایی است که interaction واقعی ثبت می‌شود: key press، mouse movement، touch، sensor change، device signal یا هر رویداد دیگر.

به همین دلیل، Layer 1 جایی است که مدل با واقعیت فیزیکی و پلتفرمی روبه‌رو می‌شود. تمام انتزاع‌های بالاتر در نهایت باید از طریق system اجرا شوند.

### محدودیت و قابلیت

System هم توانایی می‌دهد و هم محدودیت ایجاد می‌کند. ممکن است پلتفرمی از یک نوع window پشتیبانی کند و دیگری نه. ممکن است دسترسی به دستگاه نیازمند permission باشد. ممکن است hardware خاصی وجود نداشته باشد. CatalystUI این تفاوت‌ها را در Layer 1 و connector مربوط به آن متمرکز می‌کند تا لایه‌های بالاتر بتوانند تا حد ممکن پایدار و قابل انتقال بمانند.
