# 5.1 The Stack :: Data Storage

## بحث عمیق

### لایه ضمنی پیش از داده فعال

**Data Storage** بالاترین لایه ضمنی Stack است. این لایه هر مکان یا سازوکاری را نشان می‌دهد که داده می‌تواند در آن نگهداری شود پیش از آنکه وارد جریان فعال رابط شود. فایل‌سیستم، پایگاه داده، حافظه، cache، سرویس وب، API، پیام شبکه، فضای ابری، stream یا حتی یک منبع سفارشی همگی می‌توانند نقش Data Storage را داشته باشند.

این لایه «ضمنی» است چون مدل CatalystUI معمولاً خودِ ذخیره‌ساز را مستقیماً پیاده‌سازی یا کنترل نمی‌کند. Stack از زمانی صریح می‌شود که داده به‌عنوان **Layer 7: Digital Data** وارد جریان فعال شود. با این حال، Data Storage همچنان برای فهم منشأ داده اهمیت دارد.

### تولیدکننده Digital Data

Data Storage را می‌توان تولیدکننده Digital Data دانست. وقتی برنامه فایلی را باز می‌کند، پاسخی را از سرور دریافت می‌کند، رکوردی را از پایگاه داده می‌خواند یا داده‌ای را از حافظه می‌گیرد، آن اطلاعات از جایی می‌آید. آن «جا» بخشی از Data Storage است.

اما ذخیره شدن داده با تفسیر شدن آن یکی نیست. یک فایل ممکن است bytes مرتب داشته باشد، اما تا زمانی که وارد جریان فعال نشود و توسط لایه‌های بعدی خوانده نشود، برای رابط فقط یک منبع بالقوه است. Data Storage امکان وجود و دوام داده را فراهم می‌کند؛ Stack فعال، آن داده را به تجربه قابل تعامل تبدیل می‌کند.

### چرا مستقیم مدل نمی‌شود

CatalystUI این لایه را صریح نمی‌کند چون شکل ذخیره‌سازی می‌تواند بی‌نهایت متفاوت باشد. یک برنامه ممکن است از فایل محلی استفاده کند، برنامه دیگر از SQLite، دیگری از REST API، و دیگری از یک دستگاه embedded. اگر مدل بخواهد تمام این موارد را به‌صورت لایه‌ای صریح تعریف کند، از هدف خود دور می‌شود.

به جای آن، مدل می‌گوید هرجا داده ذخیره شده باشد، وقتی وارد سیستم رابط می‌شود باید به **Digital Data** تبدیل یا نمایان شود. اتصال‌دهنده Data سپس می‌تواند آن داده را به Structure & Semantics وصل کند.

### رابطه با اتصال‌دهنده Data

اگرچه Data Storage خارج از Stack صریح است، اتصال‌دهنده **Data** اغلب با آن ارتباط نزدیک دارد. Data connector ممکن است فایل را باز کند، stream را بخواند، query را اجرا کند یا response را دریافت کند. اما نقش مفهومی آن این است که داده ذخیره‌شده را وارد جریان کند و آن را به Layer 7 و سپس Layer 6 برساند.

به زبان ساده: Data Storage جایی است که داده منتظر می‌ماند؛ Digital Data جایی است که داده وارد صحنه می‌شود.
