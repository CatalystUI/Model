# 5.2 The Stack :: Digital Data

## بحث عمیق

### نخستین لایه صریح

**Digital Data** نخستین لایه صریح Stack است. این لایه اطلاعاتی را نشان می‌دهد که به شکلی رایانه‌خوان، معمولاً بر پایه 1 و 0، در جریان فعال سیستم حاضر شده است. فایل، سند، buffer، stream، payload، پاسخ شبکه یا رشته‌ای از bytes همگی می‌توانند نمونه‌هایی از Digital Data باشند.

در این لایه، داده وجود دارد و سیستم می‌تواند آن را بخواند یا جابه‌جا کند، اما هنوز الزاماً نمی‌داند آن داده چه معنایی دارد. یک رشته bytes ممکن است متن، تصویر، صوت، پیکربندی، executable یا چیزی کاملاً دیگر باشد. تا زمانی که ساختار و semantics آن روشن نشود، فقط داده دیجیتال است.

### داده بدون تفسیر کافی نیست

Digital Data بسیار مهم است، اما به‌تنهایی برای رابط انسانی کافی نیست. انسان معمولاً bytes خام را نمی‌بیند و درک نمی‌کند. حتی اگر ببیند، بدون قرارداد مناسب نمی‌داند آن bytes چه چیزی را نشان می‌دهند. بنابراین این لایه نقطه آغاز است، نه مقصد.

مدل این تمایز را صریح می‌کند تا داده ذخیره‌شده، داده خوانده‌شده و داده تفسیرشده با هم اشتباه گرفته نشوند. یک فایل MP3 در Layer 7 ممکن است فقط یک توالی bytes باشد. در Layer 6، آن bytes بر اساس semantics فایل MP3 تفسیر می‌شوند. در لایه‌های بعدی، همان داده می‌تواند به component صوتی، graph پخش، renderer صوتی و خروجی شنیدنی تبدیل شود.

### نمایش فعال

Digital Data در Stack «فعال» است؛ یعنی در محدوده کاری رابط قرار گرفته است. ممکن است هنوز از Data Storage آمده باشد، اما اکنون برنامه آن را در اختیار دارد یا به آن دسترسی منطقی پیدا کرده است. این تمایز کمک می‌کند بفهمیم چه زمانی داده فقط ذخیره شده و چه زمانی وارد چرخه تعامل شده است.

### بدون ساختار، بدون معنا

این لایه هنوز structure یا semantics تعریف نمی‌کند. ممکن است داده خودش از نظر داخلی منظم باشد، اما Stack تا Layer 6 آن نظم را به‌عنوان تفسیر رسمی نمی‌پذیرد. این کار از ابهام جلوگیری می‌کند. داده ابتدا وارد می‌شود، سپس قواعد خواندن آن اعمال می‌شود، سپس به عناصر قابل استفاده تبدیل می‌شود.

### نقش در مسیر برگشتی

در مسیر پایین به بالا، Interaction Data ممکن است در نهایت باعث تغییر Digital Data شود. وقتی کاربر متنی را تایپ می‌کند، فایلی را ذخیره می‌کند، تنظیمی را تغییر می‌دهد یا عملیاتی را تأیید می‌کند، نتیجه می‌تواند به Layer 7 بازگردد تا داده دیجیتال جدید یا اصلاح‌شده آماده ذخیره‌سازی شود.
