# 6.3 Connectors :: Adapter

## بحث عمیق

### از استفاده به زمینه

اتصال‌دهنده **Adapter** میان **Layer 5: Components, Controls, & Layouts** و **Layer 4: Graphs & Frames** قرار دارد. وظیفه آن گرفتن داده mutable رابط و قرار دادن آن در زمینه‌ای بزرگ‌تر است؛ جایی که بتواند سازمان‌دهی، کشف، مسیریابی، محدود، گروه‌بندی و برای ادامه Stack آماده شود.

Layer 5 components، controls و layouts را فراهم می‌کند. این‌ها قطعاتی هستند که توسعه‌دهنده می‌تواند مستقیماً با آن‌ها کار کند. اما این قطعات به‌تنهایی کل محیطی را که در آن وجود دارند توصیف نمی‌کنند. یک component ممکن است بداند چیست و چگونه رفتار می‌کند، اما خودبه‌خود نمی‌داند در کل interface کجا قرار دارد یا چگونه با دیگر componentها ارتباط دارد.

Adapter این حرکت را از قطعات قابل استفاده به زمینه سازمان‌یافته فراهم می‌کند.

### تبدیل Componentها به Graph

یک component می‌تواند جداگانه وجود داشته باشد، اما interface معمولاً از یک component تنها ساخته نمی‌شود. حتی ساده‌ترین interface روابطی دارد: یک component ممکن است component دیگری را در خود داشته باشد، یک control ممکن است به layout وابسته باشد، گروهی از عناصر ممکن است با هم فعال، غیرفعال، جست‌وجو یا به‌روزرسانی شوند.

Graph برای همین مهم می‌شود. Adapter componentها را طوری به graph معرفی می‌کند که سیستم بتواند روابط و مسیرهای آن‌ها را بفهمد. این کار ممکن است شامل افزودن nodeها، تعریف parent/child، ثبت controlها، پیوند layoutها، یا ساخت index برای lookup باشد.

### آماده‌سازی Frame

Adapter فقط graph نمی‌سازد؛ می‌تواند داده لازم برای frame را نیز آماده کند. Frame باید بداند در زمینه فعال چه چیزهایی وجود دارند، bounds چگونه تعریف می‌شوند، کدام componentها باید در rendering شرکت کنند، و interaction چگونه باید در این زمینه حرکت کند.

Adapter کمک می‌کند Layer 4 با داده‌ای روبه‌رو شود که از نظر زمینه آماده‌تر است. در واقع، Parser اطلاعات ساختاری را usable می‌کند؛ Adapter اطلاعات usable را contextual می‌کند.

### مرز سالم مسئولیت‌ها

Adapter نباید منطق داخلی componentها را ببلعد و نباید خودش renderer شود. کار آن اتصال Layer 5 و Layer 4 است. این جداسازی اجازه می‌دهد componentها قابل استفاده باقی بمانند، graphها سازمان‌دهنده باقی بمانند، و تغییر هر بخش کل سیستم را نشکند.

### مسیر برگشتی

در مسیر interaction، graph و frame ممکن است بفهمند کدام control باید رویداد را دریافت کند. Adapter می‌تواند نقش ترجمه‌ای داشته باشد تا interaction از زمینه Layer 4 دوباره به component یا control مناسب در Layer 5 برسد. این یعنی Adapter هم در جریان بالا به پایین و هم پایین به بالا اهمیت دارد.
